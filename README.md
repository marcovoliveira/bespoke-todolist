# TODO List

A clean, interactive task manager with persistent storage. Add tasks, mark them complete, and pick up right where you left off.

## How It Works
- Add new tasks via the input field
- Click the checkbox to mark tasks complete (strikethrough effect)
- Tasks persist across sessions via a backend API

## Features
- Add and toggle tasks
- Real-time sync with REST API (GET, POST, PUT)
- Smooth UI with visual feedback on completion
- Responsive design

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
- REST API integration
